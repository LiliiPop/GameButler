## 修复与改进

- **「开始」「立即开始」不再多出一条「今天的任务」**：开始一个游戏、单项任务里点「立即开始 / 加入队列」、「继续」，都改成把今天日程里本来就有这些任务的那一条（例如「日常」）挪到现在或队尾，只跑这几项，跑完回到原来的定时。只有哪个预设都不包含的任务才另加一条。「再跑一次」也会把今天做过的再跑一遍。
- **「加入队列」里到了时段的任务先跑**：排在队列里、只在某个时段跑的任务（例如时绘「领体力 · 午间」12:00–15:00），时段开着就先跑这几项，不再等前面在等闲时的预设，免得等到时段过了。其余任务照旧排队。定时编辑里「加入队列」的说明也改了。
- **活动甘特图按游戏日画**：每一格是一个游戏日（从刷新时间开始，只看一个游戏时按它的刷新时间），表示「现在」的竖线和「今天」那格对得上。「10月22日更新后」这类没写具体时刻的活动，按那个游戏的刷新时间开始（代号鸢 05:00、原神 04:00）。表头的日期格子和下面的格子对齐了。
- **标为已完成**：
  - 游戏页「运行记录」里今天失败的任务，右键可以立刻重跑、标为已完成或跳过。
  - 「今日任务」里跳过了的任务，右键从「不跳过了」换成「标为已完成」（要跑就点「再跑一次」），因为跳过的任务在日常一览里还算没做完。
- **定时**：可以先选「每周」再勾哪几天，没勾不能保存。运行时段按北京时间填，下面写换算成电脑本地时间是几点。
- 任务预设：有只在某个时段跑的任务、但这套没有定时的，卡片上会提醒加一个「每天」的定时。新建预设回到看板时不再弹回最左边。
- 运行行直接放「跳过当前任务」「跳过当前序列」两个按钮，去掉了重复的「⋯」菜单。
- 抽卡资源的几项排成一样的格子，「多少 = 1 抽」的换算只在鼠标提示里显示。

## 升级

v0.1.2 及以后的版本会自动更新到这一版（设置 →「管家更新」，或等它自己查到）。更新后从托盘「退出」再打开一次管家。
从 v0.1.0 / v0.1.1 升级请手动：下载下面的 zip 解压，把旧文件夹里的 data 文件夹（和改过的 config/butler.toml）复制过去。
