## 新功能

- **米游社每日签到（不用装胡桃）**：设置 →「米游社账号」→「扫码登录」，用米游社 App 扫一次码，原神、崩铁、未定事件簿的「米游社签到」都由管家自己完成，账号下每个角色都签，结果记在运行记录里。
  - 原神：任务预设里原来的「米游社签到」登录后自动改成管家签；没登录、配了胡桃的照旧打开胡桃。
  - 崩铁、未定事件簿：在任务预设「修改预设」里勾上「米游社签到」；只跑这一项时不开游戏、不开工具。
  - 米游社偶尔要求人机验证，这天会签不上，提示你在 App 里手动签一次。登录凭证只存在本机 data/mys.json，不要把 data 文件夹发给别人。
  - 扫码登录和签到的做法移植自 Snap Hutao Remastered（MIT），崩铁、未定的签到参数参照 MihoyoBBSTools（MIT），详见 docs/THIRD_PARTY_NOTICES.md。
- **新建预设可以从工具自带的预设开始**：「新建预设」里选「从头开始」，或「从 MAA 预设新建」（原神是 BetterGI 一条龙），选了自动填名字。游戏页也有「新建预设」。
- **自动重复改成整套预设**：任务预设的「自动重复」作用于这一整套（做完隔几小时再跑一轮，或到点再跑）。
- **「保存此项」**：任务预设里展开一项的保存按钮只保存这一项；下面的「保存任务预设」保存整套。
- 活动页上面那排游戏可以按住拖动排序；任务预设看板在空白处按住可以左右拖动。

## 修复与改进

- 活动：TapTap 帖子不再把帖子后面「猜你想搜」、别人的帖子和评论当成正文（恋与深空「庆生日历」被认成 11/21~11/30 的活动）；「当前活动」轮播只放已经开始的活动，还没开始的只在日历里画虚线框。
- 设置里没允许进游戏读公告时，活动页不再列出游戏内来源。
- MaaSH 的「质检截图」选项不再在每个任务下面重复出现（截图由管家的「设置 → 运行记录输出 · 截图」管）。
- 挂载脚本时显示名字默认用游戏名（例如「时空中的绘旅人」）；重新挂载时也能改显示名字。「导入工具自带的预设」挪到「设置 → 工具与游戏」每个脚本那一行。
- 定时的「每天」和「每周几」不能同时选。
- 界面细节：按钮里的字不再有下划线；各块最后一行下面不画线；标题和第一行的间距统一；文字调整。

## 升级

v0.1.2、v0.1.3 会自动更新到这一版（设置 →「管家更新」，或等它自己查到）。更新后从托盘「退出」再打开一次管家。
从 v0.1.0 / v0.1.1 升级请手动：下载下面的 zip 解压，把旧文件夹里的 data 文件夹（和改过的 config/butler.toml）复制过去。
