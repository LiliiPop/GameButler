## 新功能

- **管家自己会更新了**：设置 →「管家更新」。每 6 小时查一次 GitHub 上的新版本；「自动更新」开着时自动下载，没有任务在跑时换上新文件并自动重启（大约半分钟）。你的设置和数据（data 文件夹、config/butler.toml）不动；旧文件备份在 _backup 里，出错会自动放回。也可以关掉自动更新，自己点「下载并更新」。
- **添加游戏（只看活动，不挂脚本）**：设置 → 工具与游戏 →「＋ 添加游戏」。没有脚本也能看这个游戏的活动日历和轮播（只读官网、B 站、wiki、TapTap 这些官方站外来源），总览「日常一览」里有它一行，做完了右键「标记已完成」，第二天自动变回没完成。现在支持原神、崩铁、未定事件簿、恋与深空、时空中的绘旅人、代号鸢、剑网三无界。
- **挂上以后也能导入工具自带的预设**：游戏页任务预设卡片上的「导入工具自带的预设」（MAA 的预设、MFA 的实例、工具默认勾选、BetterGI 一条龙）；重新挂载以前挂过的脚本时也可以一同导入。

## 修复与改进

- 「从常见脚本下载」「换文件夹」弹出选文件夹窗口时报「系统找不到指定的文件」：改用 Windows 自带的选文件夹窗口，不再依赖 PowerShell。
- 挂上脚本后提示找不到 interface.json / 程序：现在会自动按常见位置查找并改好路径，找不到才提示你手动选。
- 活动：B 站官方号补读更早的帖子，一条帖子里的多张图都下载（每个活动最多 12 张，按住拖动看）。
- 重启后台更快：旧后台退出时马上放开端口。
